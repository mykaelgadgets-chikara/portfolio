# Portfolio — Tobechukwu Onyegbule

A single-file portfolio site. AI &amp; Automation Operator · Prompt Engineering Trainer · Lagos, Nigeria.

Everything is in **`index.html`** — no build step, no dependencies (fonts load from Google Fonts).

## One-click deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/mykaelgadgets-chikara/portfolio)
[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/mykaelgadgets-chikara/portfolio)

Either button clones this repo to your account and gives you a live URL (e.g. `your-name.vercel.app`)
that auto-redeploys on every push. Add a custom domain later from the host's dashboard.

## GitHub Pages

This repo is Pages-ready (an `index.html` at the root and a `.nojekyll` file). To serve it from GitHub:
**Settings → Pages → Build and deployment → Deploy from a branch → `main` / `root` → Save.**
Your site goes live at `https://mykaelgadgets-chikara.github.io/portfolio/`.

## Run locally

Open `index.html` in a browser. That's it.

## Edit

All content and styling live in `index.html`. It's theme-aware (light/dark) with a toggle, and responsive
down to phone width.
